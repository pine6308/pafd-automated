# HealthReminder 健康提醒助手

Mac 桌面端健康提醒应用，定时提醒久坐办公族进行 4 种小活动：**站起来、喝水、提肛、颈椎运动**。

---

## 核心功能

### 阶段一功能（已实现）

| 功能 | 说明 |
|------|------|
| **4 种提醒** | 站立（45 分钟）、喝水（60 分钟）、提肛（90 分钟）、颈椎（60 分钟），每种可单独开关 |
| **菜单栏图标** | 托盘 Tray 常驻菜单栏，左键打开主窗口，右键菜单操作 |
| **开始 / 暂停** | 右键托盘 →「开始提醒」或「暂停提醒」，状态持久化，重启后保持 |
| **系统通知** | 到点弹出 macOS 系统通知，点击通知可唤起主窗口 |
| **主窗口** | 欢迎页 + 使用说明，关闭窗口不退出，从托盘可再次打开 |
| **本地持久化** | 提醒配置与运行状态由 electron-store 保存，重启不丢失 |

### 阶段二功能（已实现）✨

| 功能 | 说明 |
|------|------|
| **🌸 小红花奖励系统** | 每完成一次提醒获得一朵小红花，可爱的红色花瓣+黄色花心设计 |
| **🎯 标记已完成** | 主界面和悬浮窗口都可标记完成，立即获得小红花奖励 |
| **📊 今日进度追踪** | 实时显示每种提醒类型的今日完成进度和小红花数量 |
| **🎨 桌面悬浮窗口** | 可拖动的透明毛玻璃悬浮窗，显示进度和小红花，支持切换提醒类型 |
| **✨ 动画效果** | 获得小红花时的弹跳动画、闪烁星星、呼吸浮动等可爱效果 |
| **💾 数据持久化** | 小红花数量、窗口位置、显示状态等自动保存 |
| **🔔 增强通知** | 通知中显示今日已获得的小红花数量，激励完成任务 |

### 阶段三功能（最新）🎯

| 功能 | 说明 |
|------|------|
| **🧘 互动式跟练窗口** | 模态窗口设计，屏幕居中显示，支持ESC关闭和点击遮罩关闭 |
| **🌼 提肛运动动画** | 手绘风格菊花动画，12片花瓣随收缩/保持/放松节奏动态变化 |
| **🦴 颈椎运动动画** | 简笔画风格头部转动动画，配合左转/右转/回正动作指引 |
| **⏱️ 智能倒计时** | 实时显示当前动作和剩余时间，动作进度条实时更新 |
| **📈 训练进度追踪** | 显示当前组数和总进度，进度条带闪烁效果 |
| **🎮 训练控制** | 支持暂停/继续、跳过当前组等操作 |

## 快速开始

```bash
# 安装依赖
npm install

# 开发模式（编译主进程 + 同时启动 Vite 与 Electron）
npm run dev

# 构建生产版本
npm run build
```

- **开发**：主进程入口为 `dist-electron/main/index.js`，渲染进程由 Vite 在 `http://localhost:5173` 提供。
- **生产**：构建后主进程在 `dist-electron/`，渲染静态资源在 `dist/renderer/`；可通过 `electron .` 运行或再使用 electron-builder 打包为 .app。

## 脚本说明

| 命令 | 说明 |
|------|------|
| `npm run dev` | 编译主进程后，并发启动 Vite 与 Electron，窗口加载开发服务器 |
| `npm run build` | 编译主进程 + Vite 构建渲染进程到 `dist/renderer` |
| `npm run build:main` | 仅编译主进程到 `dist-electron` |
| `npm run preview` | 仅预览 Vite 构建后的渲染端（不启动 Electron） |

## 使用说明

### 基础操作

1. **启动应用**：运行 `npm run dev` 或运行打包后的应用，菜单栏会出现托盘图标。
2. **开始提醒**：右键托盘图标 →「开始提醒」，到点会收到系统通知。
3. **暂停提醒**：右键托盘图标 →「暂停提醒」。
4. **打开主窗口**：左键点击托盘图标，或右键 →「设置」。
5. **退出**：右键托盘图标 →「退出」（关闭主窗口只会隐藏，不会退出）。

### 小红花系统

1. **获得小红花**：
   - 在主界面卡片上点击「✓ 标记已完成」按钮
   - 在桌面悬浮窗口点击「✓ 标记已完成」按钮
   - 完成后会播放可爱的弹跳动画，小红花数量 +1

2. **查看进度**：
   - 主界面：每个提醒卡片显示今日小红花数量
   - 悬浮窗口：显示当前类型的进度条和小红花数量
   - 底部统计：查看所有类型的完成次数和小红花总数

3. **桌面悬浮窗口**：
   - 可以拖动到屏幕任意位置
   - 支持切换不同的提醒类型（下拉选择）
   - 关闭主窗口后悬浮窗口仍然显示
   - 点击"隐藏/显示悬浮窗口"按钮控制显示状态

### 跟练窗口使用

1. **开始跟练**：
   - 在提肛或颈椎卡片上点击「开始跟练」按钮
   - 跟练窗口会弹出，显示实时动画和倒计时
   - 跟随动画指引完成训练

2. **训练控制**：
   - **暂停/继续**：随时暂停训练，恢复时从断点继续
   - **跳过**：跳过当前组，直接进入下一组
   - **关闭**：点击右上角 ✕、按ESC键、或点击遮罩层关闭窗口

3. **训练节奏**：
   - **提肛运动**：收缩5秒 → 保持5秒 → 放松10秒，共10组（约3分20秒）
   - **颈椎运动**：左转3秒 → 保持2秒 → 回正2秒 → 右转3秒 → 保持2秒 → 回正2秒，共8组（约2分钟）

4. **完成奖励**：
   - 完成所有组数后会播放庆祝动画
   - 自动标记为已完成并获得小红花
   - 2秒后自动关闭窗口

### 数据说明

- 小红花数据按日期和类型分别存储
- 每天从零开始累计
- 所有数据自动保存到本地，重启后不丢失
- 悬浮窗口的位置、显示状态会自动记住
- 跟练完成记录自动保存，计入小红花统计
